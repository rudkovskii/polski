# Polski — уроки и тренажёр (PWA)

Приложение для изучения польского: SRS-тренажёр слов, уроки с грамматикой, 6 режимов практики,
месячная программа и «Собес». Работает офлайн, ставится на iPad/телефон как приложение.
Чистый HTML/JS без сборки — «открыл файл и работает».

## Что где лежит (если захочешь править контент)

| Файл | Что внутри |
|---|---|
| `data/vocab.js` | Слова тренажёра: `[день, польский, русский, произношение, пример PL, пример RU]` |
| `data/days.js` | Диалоги и «миссии дня» |
| `data/curriculum.js` | Карта курса (цели и навыки) |
| `lessons.js` | Уроки (недели 1–4). Формат шагов описан вверху файла |
| `program.js` | План месяца (4 недели × 7 дней) и мини-диалоги |
| `sobes.js` | Банк вопросов к собесу на ПМЖ |
| `index.html` | Вёрстка, движок тренажёра, роутер экранов |
| `practice.js` | 6 режимов практики (конструктор, перевод, аудирование, говорение, пары, пропуск) |
| `store.js`, `srs.js` | Хранилище прогресса и алгоритм повторений |
| `sw.js` | Офлайн-кэш. **При каждом обновлении поднимай номер версии** (`polski-v5` → `v6`) |

## Как обновить контент (простыми словами)

1. Открой нужный файл из таблицы выше в текстовом редакторе.
2. Поправь/добавь строки, сохраняя формат (запятые, кавычки — как у соседних строк).
3. Открой `sw.js` и увеличь версию кэша на 1 (`polski-v5` → `polski-v6`) — иначе на устройствах
   останется старая версия.
4. Загрузи изменённые файлы обратно (см. «Как выложить онлайн»). Прогресс пользователей **не сбросится**:
   слова привязаны к устойчивым ID, а не к порядку в списке.

## Как выложить онлайн (GitHub Pages) — без терминала

**Способ 1. GitHub Desktop (рекомендую, если не любишь командную строку):**
1. Установи GitHub Desktop (desktop.github.com) и войди в свой GitHub.
2. File → Add Local Repository → выбери эту папку (`app`). Она уже подготовлена как репозиторий.
3. Кнопка **Publish repository** (можно оставить публичным). Готово — код на GitHub.
4. На github.com открой репозиторий → **Settings → Pages** → Source: ветка `main`, папка `/ (root)` → Save.
5. Через минуту появится ссылка вида `https://твой-логин.github.io/polski/`.

**Способ 2. Один раз через терминал (если решишься):**
```
gh auth login          # войти в GitHub (откроется браузер)
```
после этого скажи мне — я создам репозиторий и залью всё сам.

## Поставить на iPad как приложение

1. Открой ссылку `https://…github.io/polski/` в **Safari** на iPad.
2. Кнопка «Поделиться» → **«На экран Домой»**.
3. Появится иконка — запускается как обычное приложение, работает офлайн.
